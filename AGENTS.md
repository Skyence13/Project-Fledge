# Working on Project Fledge

Start with [the project handoff](docs/HANDOFF.md) and its linked [Wisp implementation brief](docs/Project_Fledge_Wisp_Implementation_Brief.md). The brief sets the current experiment. The research and design documents describe longer-term goals.

Use the [README](README.md) in this checkout for the commands to launch the teaching room, run an experiment, and execute the tests.

When changing learning or evolution, keep three things independently recoverable: the inherited genome, the state of one Wisp's lifetime, and the experimenter's hidden lesson. Keep new offspring independent of their parents' learned weights. Compare experimental conditions using matched task budgets and held-out lessons, and identify the controls and seed when reporting a result.
