# Project Fledge

Project Fledge is an experimental framework for evolving and teaching an embodied artificial mind called a Wisp. The first laboratory is virtual, with physical embodiment planned after the learning experiments.

## Start here

Read the [Codex handoff](docs/HANDOFF.md) for the current design decisions, implementation plan, and next experiment. Prototype work is reviewed in [pull requests](https://github.com/Skyence13/Project-Fledge/pulls).
